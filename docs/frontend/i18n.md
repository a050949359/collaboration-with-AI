# 前端國際化（i18n）

前端文字用 [vue-i18n](https://vue-i18n.intlify.dev/) 管理，設定在 [resources/js/i18n/index.ts](../../resources/js/i18n/index.ts)。

---

## 1. 設定與語系

```ts
// i18n/index.ts
const i18n = createI18n({
    legacy: false,                 // Composition API 模式
    locale: savedLocale,           // 預設讀 localStorage('locale')，否則 'zh-tw'
    fallbackLocale: 'en',          // 找不到 key 時退回英文
    messages: { 'zh-tw': zhTw, en },
});
```

- 支援語系：**`zh-tw`（預設）** 與 **`en`**。
- 目前語系存在 `localStorage` 的 `locale` key。
- 切換語系用匯出的 `setLocale('zh-tw' | 'en')`，會同時更新 `localStorage` 與當前 locale；`getLocale()` 取目前值。

---

## 2. 語系檔結構

訊息檔在 [resources/js/i18n/locales/](../../resources/js/i18n/locales/)：`zh-tw.ts` 與 `en.ts`，兩者結構必須**對齊**（同樣的 key 樹）。

```ts
// locales/zh-tw.ts
export default {
    common: {
        loading: '載入中...',
        total: '共 {total} 筆，第 {current} / {last} 頁',   // {} 是參數插值
    },
    articles: {
        nav: { home: '首頁', articles: '文章', /* ... */ },
    },
};
```

- 巢狀分組，用點號路徑取用（`common.loading`、`articles.nav.home`）。
- `{xxx}` 是插值參數。

---

## 3. 元件裡使用

```ts
import { useI18n } from 'vue-i18n';

const { t } = useI18n();

t('common.loading');                        // → '載入中...'
t('common.total', { total: 50, current: 1, last: 5 });   // 帶參數
```

導覽列 label 就是這樣取的（`defaultNavLinks` 裡的 `t('articles.nav.home')`），見 [./routing.md](./routing.md)。

---

## 4. 與後端 enum 的分工（重要）

合法值的單一來源在後端 enum（注入方式見 [../architecture.md](../architecture.md)），但**顯示文字屬於前端職責**：

| 東西 | 放哪 | 為什麼 |
|---|---|---|
| 合法值（enum values） | 後端 enum → `pageProps` 注入 | 是業務規則，需單一來源 |
| 顯示文字（label） | 前端 i18n（或 `statusLabels` 之類的 map） | 純顯示、要隨語系變 |
| 顏色（CSS class） | 前端（`statusColors`） | 純樣式 |

所以新增 enum case 時：後端加 case → **前端補 i18n 文字 + 顏色**，兩邊各補各的，不重複定義合法值。

---

## 5. 新增文字 / 新語系 checklist

新增一段文字：

1. 在 `zh-tw.ts` 加 key。
2. 在 `en.ts` 加**同一個 key**（缺了會 fallback 到英文，但英文也缺就顯示 key 本身）。
3. 元件用 `t('your.key')` 取用。

新增一個語系（例如 `ja`）：

1. 新增 `locales/ja.ts`，複製 `zh-tw.ts` 的 key 樹後翻譯。
2. `i18n/index.ts` 的 `messages` 加 `ja`，並把 `setLocale` 的型別 union 補上 `'ja'`。
3. 提供切換入口（呼叫 `setLocale('ja')`）。
